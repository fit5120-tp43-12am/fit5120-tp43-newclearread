# Training History

This folder contains sanitized historical records from the LoRA training workflow.

| Folder | Purpose |
| --- | --- |
| `work_orders/` | Task specifications for each training stage. |
| `decision_reviews/` | Worker outcomes and central review decisions. |
| `run_logs/` | Selected run logs for smoke training, full training, validation audit, and final test evaluation. |
| `internal_planning/` | Original planning protocol and master plan retained for traceability. |

- `../docs/experiment_history.md`
