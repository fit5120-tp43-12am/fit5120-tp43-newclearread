I am building a website called Clearead.
The website is a reading support platform for users aged 18–22 with dyslexia.
The goal is to help users read long or dense text more easily by improving content access, quick understanding, reading comfort, and audio support.


Main pages I need
1. Home Page

This page should introduce the website clearly.

Include:

Website name: Clearead
A short tagline, such as:
Make reading clearer, easier, and more supportive.
A brief introduction explaining that the website helps users with dyslexia read text more comfortably
A short feature overview section
A clear button such as Start Reading or Go to Reading Page

Design expectations
Keep the UI simple and student-friendly
Do not make it look too medical or too technical
Focus on readability and clarity
Make the reading page the main feature
Use cards, sections, and clear spacing
The summary area and original text should be visually distinct
The page should look like a real usable prototype, not just a wireframe
